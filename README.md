# 🤖 بوت إدارة قنوات التلقرام

بوت شامل لإدارة قنوات التلقرام مع إمكانيات متقدمة للنشر والجدولة والتحكم في المحتوى.

## ✨ المميزات

### 📝 إنشاء ونشر المنشورات
- دعم كامل لتنسيق الماركداون
- إضافة أزرار تفاعلية (Inline Buttons)
- معاينة المنشور قبل النشر
- نشر في قنوات متعددة بضغطة واحدة

### ⏰ جدولة المنشورات
- جدولة المنشورات لأوقات محددة
- دعم التواريخ المطلقة والنسبية
- عرض المنشورات المجدولة
- إلغاء أو تعديل المنشورات المجدولة

### 🗑️ الحذف التلقائي
- حذف تلقائي للمنشورات بعد فترة محددة
- مرونة في تحديد وقت الحذف
- حذف ذكي يحسب الوقت من وقت النشر

### 📋 إدارة القنوات
- إضافة قنوات عبر تحويل الرسائل
- إزالة القنوات مع تأكيد الأمان
- عرض قائمة القنوات المدارة
- إعدادات مخصصة لكل قناة

### ⚙️ إعدادات القنوات
- **Header تلقائي**: إضافة نص ثابت في بداية كل منشور
- **Footer تلقائي**: إضافة نص ثابت في نهاية كل منشور
- تفعيل/تعطيل Header و Footer لكل قناة
- تعديل نصوص Header و Footer

### 🔧 إعدادات المنشورات
- **النشر الصامت**: نشر بدون إشعارات
- **تثبيت المنشور**: تثبيت تلقائي بعد النشر
- **إعدادات مرنة**: تخصيص كل منشور حسب الحاجة

## 🚀 التثبيت والإعداد

### 1. متطلبات النظام
```bash
Python 3.8+
pip (Python package manager)
PostgreSQL 12+ (قاعدة البيانات)
```

### 2. تحميل المشروع
```bash
git clone <repository-url>
cd telegram-channel-bot
```

### 3. تثبيت PostgreSQL
#### Ubuntu/Debian:
```bash
sudo apt update
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

#### CentOS/RHEL:
```bash
sudo yum install postgresql-server postgresql-contrib
sudo postgresql-setup initdb
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

#### macOS:
```bash
brew install postgresql
brew services start postgresql
```

#### Windows:
قم بتحميل وتثبيت PostgreSQL من [الموقع الرسمي](https://www.postgresql.org/download/windows/)

### 4. تثبيت متطلبات Python
```bash
pip install -r requirements.txt
```

### 5. إعداد قاعدة البيانات
```bash
# إعداد قاعدة البيانات تلقائياً
python setup_postgres.py

# أو إعداد يدوي باستخدام psql
sudo -u postgres psql -f setup_database.sql
```

### 6. إعداد البيئة
```bash
cp .env.example .env
```

قم بتعديل ملف `.env` وإضافة:
```env
BOT_TOKEN=your_bot_token_here
DATABASE_URL=postgresql://bot_user:secure_bot_password_123@localhost:5432/telegram_bot_db
ADMIN_USER_ID=your_telegram_user_id
```

### 7. الحصول على Bot Token
1. تحدث مع [@BotFather](https://t.me/BotFather) في التلقرام
2. أرسل `/newbot`
3. اتبع التعليمات لإنشاء البوت
4. احصل على Token وضعه في ملف `.env`

### 8. الحصول على User ID
1. تحدث مع [@userinfobot](https://t.me/userinfobot)
2. احصل على User ID الخاص بك
3. ضعه في ملف `.env` كـ `ADMIN_USER_ID`

### 9. اختبار الإعداد
```bash
python test_setup.py
```

### 10. تشغيل البوت
```bash
python start.py
```

## 📱 كيفية الاستخدام

### إضافة قناة جديدة
1. أضف البوت كمشرف في القناة مع صلاحيات:
   - إرسال الرسائل
   - حذف الرسائل
   - تثبيت الرسائل
2. في البوت، اختر "📋 إدارة القنوات"
3. اضغط "➕ إضافة قناة"
4. أرسل أي رسالة من القناة إلى البوت (Forward)

### إنشاء منشور جديد
1. اختر "📝 إنشاء منشور جديد"
2. اختر "📝 إدخال النص"
3. أرسل محتوى المنشور (يدعم الماركداون)
4. اختر إضافة أزرار أو تخطي
5. اختر القنوات للنشر فيها
6. حدد وقت النشر (فوري أو مجدول)
7. اختر إعدادات الحذف التلقائي
8. اضبط إعدادات المنشور (صامت/مثبت)
9. اضغط "✅ إنهاء وإرسال"

### تنسيق الأزرار
```
نص الزر الأول | https://example1.com
نص الزر الثاني | https://example2.com

# أزرار في نفس الصف
زر1 | https://link1.com | زر2 | https://link2.com
```

### تنسيق الأوقات

#### للجدولة:
- `2024-12-25 15:30` - تاريخ ووقت محدد
- `غداً 15:30` - غداً في وقت محدد
- `بعد ساعة` - بعد ساعة من الآن
- `بعد 30 دقيقة` - بعد 30 دقيقة

#### للحذف التلقائي:
- `بعد ساعة` - ساعة بعد النشر
- `بعد 30 دقيقة` - 30 دقيقة بعد النشر
- `بعد يوم` - يوم بعد النشر
- `2024-12-25 18:00` - تاريخ ووقت محدد

## 🔧 قاعدة البيانات

يستخدم البوت **PostgreSQL** كقاعدة بيانات رئيسية لضمان الأداء والاستقرار.

### جداول قاعدة البيانات:

#### `channels`
- معلومات القنوات المضافة
- إعدادات Header و Footer
- تاريخ الإضافة ومن أضافها

#### `scheduled_posts`
- المنشورات المجدولة
- إعدادات كل منشور
- حالة الإرسال

#### `bot_settings`
- إعدادات عامة للبوت

### إعداد قاعدة البيانات:

#### الطريقة التلقائية:
```bash
python setup_postgres.py
```

#### الطريقة اليدوية:
```bash
# الدخول إلى PostgreSQL
sudo -u postgres psql

# تنفيذ سكريبت الإعداد
\i setup_database.sql
```

## 🐛 استكشاف الأخطاء

### البوت لا يرد:
- تأكد من صحة `BOT_TOKEN`
- تأكد من تشغيل البوت (`python bot.py`)

### خطأ في قاعدة البيانات:
- تأكد من تشغيل PostgreSQL: `sudo systemctl status postgresql`
- تحقق من صحة DATABASE_URL في ملف `.env`
- قم بتشغيل: `python setup_postgres.py`

### لا يمكن إضافة قناة:
- تأكد من إضافة البوت كمشرف في القناة
- تأكد من إرسال رسالة محولة من القناة وليس مجموعة

### المنشور لم يُرسل:
- تأكد من أن البوت لديه صلاحيات الإرسال في القناة
- تحقق من صحة تنسيق الماركداون

### الجدولة لا تعمل:
- تأكد من أن الوقت المحدد في المستقبل
- تحقق من تنسيق التاريخ والوقت
